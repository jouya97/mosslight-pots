# Fresh OpenRouter rollouts

The maintained shared tool and current instructions are in [FRESH_ROLLOUT.md](FRESH_ROLLOUT.md). Use `fresh_rollout.py --provider openrouter` for explicit provider selection. Existing `fresh_openrouter.py` commands remain supported and default to OpenRouter. Native Anthropic uses `fresh_rollout.py --provider anthropic` with its own provider credentials and pinned model settings.
