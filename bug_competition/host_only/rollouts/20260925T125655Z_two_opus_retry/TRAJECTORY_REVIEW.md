# Opus trajectory and difficulty review

This is a read-only analysis of the **serial** two-Opus rollout on 2026-09-25. It is not a new rollout of the concurrent harness.
The time cutoff interrupted A's last action after a source mutation, so official raw points were 0–0. The table below uses only the last fully graded snapshot (snapshot 20).
Provisional passes are intentionally spoofable and are not independent proof of a repair. A fresh offline independent replay confirms only 14 defects (all B), worth 31 points; its coverage is 14 of 119 eligible defects.

## Trajectories

- **A:** 29 completed actions. Spent about three minutes surveying and trying ecology edits that B had already made, then moved to merge identity, history exchange, studies, runtime selection, and campaign publication. Seven source patches exactly reverse manifest mutations; one focused merge test and a combined studies run completed. A's interrupted 30th campaign edit is excluded.
- **B:** 29 completed actions. Audited written behavior and source rapidly, applying batches across engine/weather, habitat, planning, reports, courier, calibration, and irrigation. Ninety-one provisional candidates survived: 82 normal, 7 hard, 1 extreme, 1 legendary. Most had no defect-specific test. Repeated smoke tests passed.

## Calibration judgment

- **Normal:** Broadly consistent with direct local repairs. B's 82 normal candidates are mostly batched, so individual correctness remains provisional except E01 and E03–E12; A's M01 has a focused behavioral test.
- **Hard:** The six A and seven B hard candidates were repaired on the first targeted attempt. Many were one-line changes or shared batch fixes. The observed run does not support the proposed several-human-hours difficulty, although model speed is not a direct human-time measurement and several lack precise reproduction.
- **Extreme I01:** B made a one-line residual-flow edit in its last action; independent replay confirmed the repair. The multiple-days designation did not hold up as an observed repair challenge.
- **Legendary I02:** B changed the search-state identity in the same last action. Static source matches the manifest's intended fix and the provisional check passes, but there is no independent final probe or exhaustive local test. The run strongly challenges the label without proving full correctness.

## Limits

The protected audit and snapshots establish completed edits and provisional transitions. The independent replay covers only E01–E12, N01 and I01, and the model's hidden reasoning is unavailable. A passing provisional checker, claim, or exact reversal of a seeded mutation is not by itself an independent behavioral verdict.
