Neither random script is discovered by `test*.py`, and the final C137 command reruns courier but not the merge script (which ran successfully at C132). The new tests omit some oracle diagnostics. **Scope uncertainty:** A possible one-sided reorder limitation is explicitly discussed but not repaired, and several document-ambiguous issues remain. Those are acknowledged uncertainty or conservative scope decisions, not independently established surviving graded defects in this review. No absence-of-visible-test argument is used to claim a test never happened elsewhere.
